# Food Symphony

음식 재료를 오선지에 놓아 멜로디를 만드는 웹 작곡 놀이입니다. 재료마다 실제 악기 소리가 납니다.

| 재료 | 악기 |
|---|---|
| 🌶️ 매운 고추 | 트럼펫 |
| 🍰 케이크 | 피아노 |
| ☕ 커피 | 클래식 기타 |
| 🍋 레몬 | 바이올린 |
| 🍉 수박 | 북(타이코) |
| 🍬 톡톡사탕 | 실로폰 |

`index.html` 하나로 동작하며, 악기 샘플은 파일 안에 포함되어 있습니다.

악기 샘플: FluidR3 GM SoundFont (Frank Wen, MIT), [midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts)에서 변환된 버전.
